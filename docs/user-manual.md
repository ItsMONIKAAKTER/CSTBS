# Student User Manual — CSTBS v5.2

1. Browse public university events at `/events`.
2. Choose **Student register** (`/register`) and provide your name, email, unique **Student ID** (6–20 ASCII letters/numbers), password and confirmation. Students may register directly through the website, without an invitation.
3. Return to **Login** (`/login`) for future student email/password sessions.
4. Pick an upcoming event and open the responsive seat map, choose up to six available seats, review and confirm. Seats are rechecked before saving. All reservations are free (**¥0.00 CNY**); there is no payment step.
5. View or cancel your own bookings at `/bookings`. Successful changes create notification previews locally (or SMTP email if configured).
6. The **Admin Login** link is exclusively for existing approved administrators who have an access key from a trusted operator. A Student ID or an arbitrary role field does not grant admin access.

**Privacy:** Student ID, email, booking details and credentials must not be posted in public issues or screenshots. Sign out after using shared computers.
